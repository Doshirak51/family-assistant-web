# Family Assistant — веб-приложение

Это мобильный семейный сайт для двух человек. Он не использует Railway или сервер: работает с Supabase напрямую и безопасно ограничивает доступ правилами базы данных.

## Что есть в первой версии

- вход по ссылке на e-mail;
- одно семейное пространство на двух участников;
- приглашение партнёра безопасной одноразовой ссылкой;
- доходы и расходы, категории, баланс за месяц;
- задачи с отметкой выполнения;
- ближайшие события;
- общий список покупок.

## Подключение Supabase

1. В Supabase откройте **SQL Editor** и выполните содержимое `supabase-web.sql`.
2. Откройте **Project Settings → API Keys** и скопируйте:
   - Project URL;
   - publishable key (или legacy anon key).
3. Впишите их в `config.js`. Эти два значения можно хранить на сайте; secret/service-role ключ туда вставлять нельзя.
4. В **Authentication → URL Configuration** добавьте адрес будущего сайта в **Redirect URLs**. Пока адреса нет, можно добавить `http://localhost:3000` для локальной проверки.

## Бесплатная публикация

Проще всего опубликовать содержимое этой папки через **GitHub Pages**. Это статический сайт, поэтому Railway, сервер и платный тариф не нужны.

После публикации вернитесь в Supabase и добавьте URL GitHub Pages в Redirect URLs. Затем откройте сайт, войдите по e-mail и создайте семейное пространство. Второму человеку отправьте ссылку из «Семья → Пригласить».
